This repo contains code I created to imitate a fake online banking website using Python Flask framework for a previous training exercise.

It contains a backend SQL database that is initialized on first deployment and will retain any changes made to it. It also utilizes an authentication schema to ensure only authenticated users have access
to specific resources/data. Additionally, it contains standalone scripts that can be used to manipulate the SQL database as well as HTML, CSS, JavaScript, and Jinja code to render the web pages. 

**NOTE**
I understand that much of the data present in some of these files should never be present/visible, but due to the nature of the work and the limitations we faced, we had to make some compromises in order to provide the requested content.
